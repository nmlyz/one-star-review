A tiny single-file Python program that writes a one-line, one-star review of an everyday essential — gravity, filed as a deadpan complaint about socks sliding down inside shoes — to a text file. It uses only the Python standard library, needs no network, and is fully deterministic: every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 114 characters) to the output directory.
